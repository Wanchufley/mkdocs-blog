# 🌐 Web Projects Portfolio

Welcome to my little corner of experiments and creativity!

This page is a curated collection of small **static web pages** I’ve built — think of it as a visual sandbox where I explore design ideas, layouts, and components using just **HTML and CSS**. These aren’t full-fledged apps or dynamic websites, but rather **dummy pages** crafted to showcase what a final product *might* look like.

Each project below is embedded as an iframe, so you can interact with the designs directly from this page — no need to open a new tab. This allows you to get a real feel for the user interface, styling, and structure I had in mind when building them.<br>
> 🛠️ Note: These are purely front-end mockups. No back-end, no interactivity — just clean, static prototypes.<br>

I'll continue to add more as I create new concepts or experiment with different layouts and aesthetics.  
Feel free to scroll through, explore, and get inspired!
